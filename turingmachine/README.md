# Turing Machine

This is a Java application (with JavaFX) that recreates the board game "Turing Machine." (Exam Project 2024)

## Overview
- **Type:** School / Personal Project
- **Language(s):** Java (Maven) / JavaFX
- **Author:** Chris Branchereau

## Features
- Java recreation of the board game
- JavaFX graphical interface

## Installation

```bash
git clone https://github.com/Chris-Branchereau/TuringMachine-JavaFX.git
cd TuringMachine-JavaFX/turingmachine

# Compile the project
mvn clean compile

# Package the application into an executable JAR
mvn clean package

# Run the executable
java -jar target/*.jar
